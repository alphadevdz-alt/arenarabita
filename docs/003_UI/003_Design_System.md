# NSSMS — Design System

## Identity
The interface should follow an official Algerian governmental visual direction.

## Tokens To Define
- Primary colors.
- Secondary colors.
- Typography.
- Spacing.
- Radius.
- Shadows.
- Icons.
- Breakpoints.
- States.

## Components
Initial component inventory:
- Header.
- Navigation.
- Footer.
- Buttons.
- Inputs.
- Selects.
- Tables.
- Cards.
- Status badges.
- Modal/dialog.
- Notifications.
- Pagination.
- QR verification result.

## Applied local tokens
- Primary green `#0f6b4a` for official actions.
- Paper background `#f4f8f5` and white cards.
- Gold accent on the official seal.
- A thin national tricolor bar reserved for identity only, not for decoration of data.

These tokens remain a local visual baseline until an official identity is approved.
